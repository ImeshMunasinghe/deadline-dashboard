# Technology Context

## Stack
- **Language**: TypeScript 5.5 (strict; separate `tsconfig.app.json` / `tsconfig.node.json`)
- **UI**: React 18.3
- **Build tool**: Vite 5.3
- **Styling**: Tailwind CSS 3.4 + PostCSS + Autoprefixer (light/dark via `dark:` classes)
- **Charts**: Recharts 2.12
- **Icons**: lucide-react
- **Fonts**: self-hosted via @fontsource — `@fontsource-variable/inter`, `@fontsource/jetbrains-mono` (imported in `src/main.tsx`; works offline with the PWA)
- **Effects**: canvas-confetti (lazy-loaded via dynamic import on 100% completion)
- **PWA**: vite-plugin-pwa (autoUpdate service worker, manifest in `vite.config.ts`)
- **Testing**: Vitest 2 (`npm test`) — 15 tests in `src/utils/index.test.ts` covering countdown, daily plan, pace, normalization, and calendar grid/events
- **Linting**: ESLint flat config (`eslint.config.js`)

## Commands
```bash
npm run dev       # Vite dev server with HMR
npm run build     # tsc && vite build
npm run preview   # preview production build
npm test          # Vitest
```

## Environment Notes
- Windows development environment (PowerShell).
- No backend; browser APIs only (localStorage, URL, Blob download).
- PWA manifest icons reference `favicon.svg` in `public/`.
- Hosting: Cloudflare Pages (`npm run build` -> `dist/`; `public/_redirects` provides the SPA fallback; pin `NODE_VERSION=20`).

## Conventions Observed in Codebase
- Named exports for components/utilities; `App.tsx` uses a default export.
- Section banners via `// ─── Section ────...` comments.
- ISO date strings throughout (`dueDate`, `createdAt`, etc. as ISO strings, not Date objects).
- IDs generated by `generateId()` (`${Date.now()}-${random}`), not UUID libs.
